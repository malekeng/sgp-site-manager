# SGP Site Manager

מערכת ניהול אתרי בנייה — שי גיל פרויקטים בע"מ.

- Vanilla JS + HTML/CSS, ללא framework
- Backend: Supabase (auth + DB + storage)
- Deploy: Vercel

## מבנה
- `*.html` — דפי המערכת (login, dashboard, יומני יציקות, ברזל, טרום, כמויות, מחירים, דוחות, משתמשים)
- `css/styles.css` — עיצוב משותף
- `js/` — לוגיקה משותפת (auth, CRUD engine, מסמכים מצורפים)
- `icons/` — לוגו (SVG) ואייקון PWA
